# CarFinder

> 🚧 **Work in Progress — Actively Developing**

CarFinder is a car discovery and comparison website I'm building as a Computer Science web development project. The goal is to help users explore vehicles, search by make and model, compare specifications, and find cars that match their preferences.

## Tech stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL, accessed through PHP PDO
- **Local development:** XAMPP (Apache and MySQL)

## Current development

I'm building the project locally. Work so far includes:

- A vehicle browsing page with searchable listings
- A relational database for vehicle details such as make, model, year, price, body type, engine, horsepower, fuel economy, transmission, and drivetrain
- A "Find My Car" questionnaire concept
- Navigation and responsive page styling

## Planned improvements

- Expand and refine the vehicle catalog
- Complete car comparison and favorites features
- Improve individual car detail pages and imagery
- Connect additional pages and interactions to the database
- Test and polish the site for a complete demonstration

This repository is being set up while the project is still under development. **The current README is a project overview, not a claim that the source code or all features are already published here.** Code, screenshots, and setup instructions will be added as the project progresses.
